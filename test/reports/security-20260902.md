## Controls

- No SQL/database/query layer exists; SQL injection is removed as an attack
  surface, not represented by a mock sanitizer.
- Default local-only bind plus Host and Origin/Sec-Fetch-Site validation.
- Read-only GET route allowlist, bounded request metadata, timeouts, rate
  limiting, capped SSE clients, heartbeat, and backpressure cleanup.
- Decoded static-path containment and dotfile denial.
- Recursive credential-key redaction for JSON and SSE transport.
- Browser output encoding, dynamic-class allowlisting, HTTPS-only external
  links, defensive stream parsing, and restrictive response headers.
- Existing signer separation, no-key/no-write behavior, risk constraints,
  live-status chain gate, explicit order expiry, and receipt validation.

## Deployment Boundary

TEMPO does not implement public-user identity or authorization. Keep the server
on loopback. Any remote exposure requires TLS, authentication/authorization,
and ingress restriction at an audited reverse proxy or equivalent gateway.
